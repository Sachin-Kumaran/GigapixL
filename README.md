# 📸 GigapixL

> A modern and responsive image gallery web application built with **React, Vite, and Tailwind CSS**.

GigapixL is a sleek, user-friendly platform for browsing and viewing images. It’s created to demonstrate frontend skills with **React** and fast, scalable tooling like **Vite** along with utility-first **Tailwind CSS**. The application supports smooth navigation and a responsive UI.

---


## 🧠 Features

✨ Nice, responsive image grid layout  
✨ Search images or categories *(if implemented)*  
✨ Smooth interactive UI  
✨ Built with modern frontend tools

## 📦 Installation
Clone the repository:
```bash
git clone https://github.com/Sachin-Kumaran/GigapixL.git
```
Navigate to the project folder:
```bash
cd GigapixL
```
Install dependencies:
```bash
npm install
```
